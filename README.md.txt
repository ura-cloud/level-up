🟢 LEVEL UP — Telegram Bot + Mini App
Рабочая основа Telegram-бота с тёмным неоновым Mini App, сохранением целей и XP, каталогом миссий и оплатой Telegram Stars. Учебный ИИ, редакторы миссий и админ-панель ещё не реализованы; интерфейс честно обозначает эти ограничения.
Быстрый запуск
	1.	Установите Python 3.11+.
	2.	pip install -r requirements.txt
	3.	Скопируйте .env.example в .env.
	4.	Вставьте новый, не публиковавшийся BOT_TOKEN от @BotFather.
	5.	Укажите WEBAPP_URL — публичный HTTPS-адрес, по которому доступно приложение (например, через собственный сервер и обратный прокси).
	6.	uvicorn backend.main:app --host 0.0.0.0 --port 8000
	7.	Откройте бота, отправьте /start и нажмите «Открыть LEVEL UP».

Безопасность
Не используйте токен, ранее отправленный в чат. Отзовите его через BotFather, а новый храните только в .env на своём сервере. Файл .env нельзя коммитить в Git.

Важно перед размещением
Для единственного инстанса с SQLite необходим постоянный том и DATABASE_PATH на этом томе. Без постоянного диска данные потеряются при пересоздании контейнера. WEBAPP_URL должен быть реальным HTTPS URL, доступным из Telegram. При горизонтальном масштабировании замените SQLite на PostgreSQL и вынесите polling бота в отдельный worker.
Для удаления номера из базы пока требуется администратор; перед публичным запуском необходимо реализовать самообслуживание по удалению данных, политику конфиденциальности и контакт поддержки. Telegram не предоставляет телефон пользователя через initData — номер можно получить только через явную кнопку согласия.
